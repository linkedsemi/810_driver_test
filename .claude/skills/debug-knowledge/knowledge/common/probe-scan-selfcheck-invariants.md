# 探测/扫描式测量的自检不变量：状态改写必须读回验证 + 基线门

## 现象

"逐脚驱动 → 逐个读回"式探测（GPIO 邻接矩阵、连通扫描、总线/引脚探测）产出**看起来成立、
实则系统性错误**的结果：矩阵呈**完美下三角**（第 i 行对全部 j<i 都读成低/连通）、行内计数
**严格递增**、连通数**超过无向对上限** `N*(N-1)/2`。或反面：工具坏掉后吐出一张**全空的
"干净"矩阵**，让人以为"没接任何线"。

## 根因

1. **状态改写未生效**：`驱动`/`还原` 走了不生效的路径（写错寄存器半区、写的是只读回读位、
   被复用功能抢走、撤销调用缺失），但**不报错** —— 调用返回成功。于是单点故障**级联放大**：
   该脚此后每一行都被误读，"一根脚没还原"伪装成"全网连通"。
2. **基线不可区分**：一个**本来就低**（被外部压住）的脚，与"被我们驱动低"在本方法下读回
   完全相同 ⇒ 不先定基线，它会被算成"与一切连通"（有向星形）。

## 判定方法（免物理知识的硬闸 + 读回验证规程）

| 闸 | 内容 | 判据 |
|---|---|---|
| **上限** | 连通计数 ≤ `N*(N-1)/2`（无向对上限） | 超过在数学上不可能 ⇒ 必有假阳性，直接判"测量坏了" |
| **对称** | `i→j` 与 `j→i` 应一致 | 不一致单独列出（中间可能有二极管/驱动器），不判死但须解释 |
| **形状** | 行内计数单调递增 / 完美三角形 | 级联污染的指纹；正常稀疏矩阵不该有规律形状 |
| **基线门** | 只有"**基线为高、本行读低**"才构成一条连线证据 | 基线为低的脚**一律不产生证据**（不是标个 `?` 就完事），单列一节（如 `BASELINE_LOW`） |

**读回验证规程**（每条状态改写都要走）：
改写后**立刻读回**，不一致就重试；重试仍失败 ⇒ 标记该脚**不可用**，从"后续可驱动集"
**永久剔除**，统计里视为**无证据**（不是"连通"）。稳定判定要**轮询**（连续两次读一致）
而不是猜固定 settle 常数，并把**实测**耗时上报。

**阳性对照不足以证明方法有效**：已知好的一对（"已确认接好的跳线"）只证明**检测通路**通，
证明不了**其余脚的状态改写生效** —— 实测出现过阳性对照 PASS、整张矩阵却已坏掉的情况。
⇒ 阳性对照 **必须与不变量自检同时**具备，缺一不可。

## 处理

- 扫描/测量类工具**必须同时具备**：阳性对照 + 上限闸 + 对称性 + 还原自检 + 基线门；
  缺任一项时矩阵**不可用于任何接线结论**。
- 还原路径必须走**能真正撤销**的那条并读回验证 —— 例：`GPIO_OUTPUT → GPIO_INPUT` 的还原
  若只调"配成输入"，可能根本没撤销输出使能（见 KNOWN_ISSUES #93）。
- 已知坏闸的判据**不得放宽**：脚真的不受控就保持 FAIL，宁可少测几根脚，不可把 FAIL 改判 PASS。
