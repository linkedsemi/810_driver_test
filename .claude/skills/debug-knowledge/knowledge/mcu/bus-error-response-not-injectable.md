# 总线对未解码/被拒访问静默 ACK：外设错误分支无法注入实测（mcu 域实例 #3）

> 方法学佐证：`embedded-debug` §1（分层定位到硬件层）、§3.3（寄存器全对≠总线没问题）、§6（坑沉淀准则）。

## 现象
为覆盖外设（如 DMA）的 ERR 分支，用两类手段注入"非法访问"：
- **未映射地址**：向传输描述符填未映射地址，期望"非法地址 → 总线 ERROR 响应 → 通道 ERR 中断 → 错误回调"；
- **IOPMP 拒绝规则**：用芯片自带 IOPMP 配一条拒绝该外设访问的规则，期望"被拒 → 总线 ERROR 响应"。

实测两类**全部静默完成**：未映射地址注入 `done=1`、`st=0`（`DMA_STATUS_COMPLETE`）、`err=0`；
IOPMP 拒绝**规则确实生效**（被拒页的写未落地，写-回读确认），但传输仍 `status=1` 报完成、错误回调恒 0、
`RAW_ERR` 恒 `0x0`——**即使拒绝整个 1MB SRAM（含描述符池）**。无一进 ERR 分支，也未见总线上报错误。

## 根因
平台总线对**未解码地址**静默返回 OK，**对被 IOPMP 拒绝的访问同样静默返回 OK**——IOPMP 只丢弃事务、
不产生 ERROR 响应，事务在总线上不可见为"错误"。⇒ 该 SoC 互联对**被拒/未解码访问一律回 OKAY**，
地址/权限非法在总线上不可见。且该 DMAC（DW DMAC）**无软件置位 ERR 的寄存器**：`MASK_ERR`/`CLEAR_ERR`
只能屏蔽/清除，`RAW_*` 只读——软件缺少"人为触发"该中断的入口。

## 判定方法
1. **地址/权限注入 + 读回完成状态**：向目标外设填若干未映射地址（含高位、跨区域）并覆盖读/写两向，
   或配 IOPMP 拒绝规则拦该外设访问（**必须先写-回读确认拒绝规则确实生效**，如被拒页写未落地），
   读回全部 `COMPLETE`/`err=0` ⇒ 该总线不产生错误响应（排除"恰好某个地址被映射"的偶然）。
2. **查该外设有无强制置位手段**：重点看错误/中断标志寄存器的 `RAW_*` 是只读还是可写、有无
   `FORCE`/`SET` 类寄存器；只有 mask/clear、无 set/force ⇒ 软件无法强制该分支。
3. ① ② 同时成立 ⇒ 该错误路径**在本平台不可动态触发**。
4. **不可注入 ≠ 无法取证：同族代理实验 + 不变量判据**。对**同族/对称路径**做可实测的代理实验，
   取一条与目标状态等价的硬件不变量当判据。DW DMA 实例：用正常 TFR 完成路径取证——实测 TFR
   完成后读 `DW_DMA_CHAN_EN`（dmac1 `0x40041000`+`0x3A0`）= `0x0`，且 `dma_stop()` 返回 `0`。
   由此得**复用判据**：**TFR 完成后 `dma_stop()` 返回 0 ⟺ `ChEn` 已被硬件清零**——
   `dw_dma_stop()` 先判 `!dw_dma_is_enabled()`：ChEn=0 且 state 非 SUSPENDED ⇒ 直接 `ret=0` 早退；
   ChEn 仍置位则落到 state 校验，而 TFR 后 state 已置 `IDLE` ⇒ 返回 `-EINVAL`（且在写 `CHAN_EN`
   之前返回，判据本身不扰动寄存器）。前提：设备 ACTIVE、channel 合法。

## 处理
- 该平台的该外设错误路径**无法用驱动层手段实测**，改用**同族代理实验 + 不变量判据（判定方法 4）
  + 与对称分支的代码对称性论证 + 静态审查**替代动态注入；**不要再试更多地址/写法**。
- **代理实验的结论一律显式标注为"推论"**，不得冒充直接实测；成功路径与错误路径的硬件行为
  **必须分别取证**，不能用一条路径的实测替另一条下结论。
- 结论**不跨平台通用**：换芯片/换 DMAC 前按上述判定方法重测一次（别的总线可能真的报 ERROR 响应）。
