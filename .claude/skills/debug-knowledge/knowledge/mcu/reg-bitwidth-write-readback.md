# 寄存器位域以实测为准：写-回读鉴别实际位宽（mcu 域实例 #2）

> 方法学佐证：`embedded-debug` §1（分层定位到硬件层）、§3.3（寄存器全对≠总线没问题）。

## 现象
按寄存器头文件声明的位域掩码设定字段，功能不符预期：设到"头文件允许的上限"时外设不动作
（如 DMA 大块传输无完成中断），只有设到更小的值才工作。软件侧看不出错——值"合法"、写入不报错。

## 根因
头文件掩码按某份手册/量产硅片整定，**EVB/FPGA 实机有效位宽可能更窄**（少一位量程即减半）。
位宽由硬件决定：写到不存在的高位被硬件**静默丢弃**，读回值 ≠ 写入值，不报任何错。

## 判定方法（写-回读鉴别位宽）
向目标字段写边界值再读回，找"从哪一位开始写不进"：
- 例（dmac1 CTL1@`0x4004101c`，头文件 `DMAC_BLOCK_TS_MASK = 0xfff` 声明 12 位）：
  写 `0xfff` 回读 `0x7ff`、写 `0x800` 回读 `0x0`、写 `0x1000` 回读 `0x1000`
  → bit11 不存在，有效 **11 位**（单块上限 2047，非 4095）。
- GDB 操作：`set {int}0x4004101c = 0xfff` → `x/wx 0x4004101c`；各边界值逐一试。
- **只读手册/头文件无法暴露此差异**——写-回读是可靠判据；怀疑位宽时优先做这一步。

## 处理
- 驱动掩码/上限以**实机写-回读**为准；头文件与实机不符时按实测值设限并**上报确认**
  （EVB/FPGA 可能异于量产硅片，勿单方面改共享头文件）。
- 边界用例的常量取自实测上限（qsh-test-gen §1.6 / qsh-test-validate §1.9h）。
